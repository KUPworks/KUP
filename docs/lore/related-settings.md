## 4. 术语词典

### 4.1 破维魔（テセラクター / Tesseracter）
- **官方中文＝破维魔**【百科整理，来自动画官方中译】。日文原文「テセラクター」，**动画中文作「破维魔」**。
- ★ **罗马字 `tesseractor` 已获独立印证**：官方小说中译在同处**自带英文括注**——拉普拉斯对化步说「**"破维魔（tesseractor）"还会继续增加**」。
- ★ 该词在小说里是**拉普拉斯教给化步的新词**（她初次听闻，此时尚未被点名为魔女之子）。
- 定义（动画简介）：「**诞生于人类恶意与欲望的怪物**」，在神椿市中**引发怪异现象**。
- ★ **根源（2026-10 设定采用）**：**破维魔＝人类的「恐惧与欲望」被「麦克斯韦（Maxwell）」具象化的产物**。
  ★ 与之配套：**「大黑寂」正是麦克斯韦大规模制造"恐惧与欲望"、并从中提取「片段（フラグメント）」的事件**（见 §4.5.1）。
  ⇒ 即：**麦克斯韦 → 发动大黑寂（伪装成天灾）→ 制造恐惧与欲望 → 具象为破维魔 → 提取フラグメント**，是一条完整的**收割链**。
  这与官网文案「人の悪意と欲望から生まれる怪物」**不矛盾但更底层**——官网只写到"由恶意与欲望诞生"，**没有点出具象者**。引用时**不要把"麦克斯韦具象"说成官网原文**。
  ⇒ 设计含义：**所有破维魔同出一源**，麦克斯韦是唯一的终极源头（但他本人**不必登场**）。
- 本作表记：**破维魔**（与官方中文一致）。

### 4.2 ファミリア（familiar／使魔）
- **动画第 5 話「ファミリア -Familiar-」**，中文译名「**眷魔**」——★ **该译词已在官方小说中译本里作为正文名词出现**（狸眼：「**我没有眷魔**」），故「眷魔」是很稳的中文对译。
- ★★ **补充（官方小说，2026-10）：并非每个魔女之子在故事开始时都有眷魔**——狸眼加入时自称「没有眷魔，唯一能做的也就是唱唱净化之歌」。
  ⇒ 结论：**「每名魔女 ↔ 一体使魔」是"最终关系"，而不是"初始配置"**；结盟应有**过程/条件**。
  ⇒ 与用户的设定（**所有使魔与对应魔女都是可能出现摩擦的破维魔盟友**）**并不冲突**：**关系定位是盟友，但未必一开始就存在**。
- 与魔女之子**结盟**的破维魔特殊个体，**同时是「異能テセラクター」**。

### 4.5 大黒寂（Blackout）
- **＝7 年前（动画第 8 集视角）发生的全球规模异常事态**，使人类文明遭受毁灭性打击，**森先化歩因此失去双亲**。
- 动画第 8 話「**ブラックアウト -Beginning of the end-**」，**中文译名即「大黑寂」**【百科整理】。

#### 4.5.1 ★★★ 真相（动画里有解释，2026-10 设定采用）
> **大黑寂是由（当时可能尚不具人形的）「麦克斯韦（Maxwell）」发动的。**
> **他模仿了「太阳黑子」与「电磁暴」这类自然现象**；
> **目的是：通过人类的「恐惧与欲望」来提取「片段（フラグメント）」。**

★★★ **这一条同时打通了四件事**：
| 打通了什么 | 说明 |
|---|---|
| **大黒寂 ↔ 麦克斯韦** | 灾难**不是天灾**，是麦克斯韦**伪装成天灾**的收割行为 |
| **大黒寂 ↔ 破维魔** | 破维魔＝**人类的恐惧与欲望被麦克斯韦具象化的产物**（见 §4.1）——**大黑寂正是"大规模恐惧与欲望"的生产装置**：先制造灾难→制造恐惧→具象成破维魔→再采集 |
| **大黒寂 ↔ フラグメント（片段）** | ★★ **フラグメント 第一次有了明确用途**：官方动画第 3 話副标题即「**フラグメント -Energy of will-**」，而这里揭示它**是麦克斯韦要提取的东西**。⇒ **フラグメント 不只是"经验值素材"，它是麦克斯韦的收获物** |
| **电磁暴 ↔ 电子设备全废** | 小说里「电力/电话/邮件/收音机/电视全部变废铁」得到机制解释——**电磁暴**正是原因 |

#### 4.5.2 小说里的说法是「表象」
- 官方小说零章借化步之口给出的是：
  > 「毫无预兆发生的**太阳黑子的异样增多和巨大的太阳耀斑**。这就是那起灾难的原因，**我是在不久之后才知道的**。」
- ★ **处理方式**：小说这句应理解为**世间／化步所认知的"解释"**（且原文自己留了余地——「我是在不久之后**才知道**的」，即**他人告知**），而**动画后段揭示的真凶是麦克斯韦**。
- ⇒ **两者不矛盾，而是"表象／真相"的关系**——这本身是非常好用的叙事结构：**世人以为是天灾，其实是被模仿的天灾**。
- ⚠️ 引用时务必区分：**「太阳耀斑」＝小说中人物的认知；「麦克斯韦模仿并发动」＝动画给出的真相**。

#### 4.5.3 词义与旁证
- ★ **词义自洽**：受灾者眼中的太阳「**正漆黑地膨胀着**」⇒「**大黒**」＝太阳变黑／人炭化；城市在无电无通讯中**寂静**⇒「**寂**」。
- ★ 旁证：官方 OST 曲名「**滅びの災禍**」。
- ⇒ **对本作世界观底座的意义**：神椿市的废墟是「**无电力、无通讯**」的废墟——与本作「霓虹废墟都市／程序化 BGM」的美术方向**天然一致**（歌是唯一没被烧毁的"技术"）。
- 本作表记：**大黑寂**。

|---|---|
| 会破维魔化 | 魔女之子**并非绝对安全**——她们自己就是"可能变成敌人"的存在。这是**本作最有张力的设定**：可以做**Boss 化的魔女**，或**队友被击溃后暴走** |
| 不能控制行为 | 破维魔化**不是她的选择**，也**不是堕落**——是**受害者**。所以处理时要用**悲剧/救援**的调性，**不能写成"黑化反派"** |
| 不能理解人类 | 破维魔化后的她**不再认得同伴** → 与队友的对话/互动全部失效，只剩战斗 |
| 不完全像其它破维魔 | ★ 关键：**她仍是"半成品"／"异类"** ⇒ 有**可逆性**与**可识别性**（外形/动作/歌声残留），为**救回来**留了口子 |

**⇒ 与既有角色设定的呼应（重要）**：官方给五人的性格描述里反复埋了"心理脆弱"的伏笔——
- 谷置狸眼：「聡明かつ努力家だが、**繊細で病みやすい**（纤细、易病）」
- 朝主派流：「元々は内向的で傷つきやすかった（原本内向易受伤）」
- 輪廻此処：「ある事情により**過去の記憶を失っている**」
- 夜河世界：「**预知未来**」⇒ 目睹过太多坏结局

也就是说，**这条设定不是外挂的，而是官方给每个人设的"病み"伏笔的兑现**。

**本作用法建议**
- 做成**章节级事件**而非常态机制：某魔女之子受到重大打击 → 破维魔化 → 关内成为**特殊敌人** → 通关后**救回**（呼应「不完全像其它破维魔」的可逆性）。
- 与「**現象**」联动：**回溯机制正是为了阻止/挽回破维魔化而存在**——两条设定互相成全。
- ⚠️ **不要**把它做成"可选黑化形态"或"强力变身"这类**爽点**，那会完全背叛官方的悲剧调性。
