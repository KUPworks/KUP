## 1. ★ 世界观骨架（10 条，看完就能上手）

1. **★ 世界线定位＝「缝合」**：本作**不是只站某一条官方主线**，而是**把「现实世界线」＋「TV 动画」＋「游戏（REGENERATE／協奏中／VIRTUAL REALITY）」等多条世界线缝合成一个故事**。官方「**REGENERATE → 动画**」仍是**主干与骨架**（制作人笔记：REGENERATE 是系列未来的核心、其世界线「延续到动画」），其余世界线作为**素材层**接入。
   ★ **缝合的边界见 §1.1**（缝了什么、没缝什么、为什么）。
2. **城市**：**神椿市**——「与现实不同历史」的平行世界中的**研究学園都市**，七年前被**大黒寂**毁灭级打击后靠先端科学奇迹复兴。
3. **灾难真相**：**大黒寂＝麦克斯韦（Maxwell）发动**，他**模仿太阳黑子与电磁暴现象**，目的是**通过人类的恐惧与欲望提取「片段（フラグメント）」**。（小说里「太阳耀斑」的说法是**表象**，原文亦写「我是在不久之后**才知道**的」。）
4. **敌人**：**破维魔（テセラクター）＝人类的恐惧与欲望被麦克斯韦具象化的产物**，引发怪異事件「**Q**」。
   ⇒ 完整收割链：**麦克斯韦 → 大黑寂（伪装成天灾）→ 制造恐惧与欲望 → 具象为破维魔 → 提取フラグメント**。
5. **主角**：**魔女之子**（日文「魔女の娘」／官方英译 Witchlings）五人——**森先化歩・谷置狸眼・朝主派流・夜河世界・輪廻此処**。**「歌は、魔法——」歌声是唯一能对抗破维魔的力量。**
6. **使魔**：**ファミリア／眷魔**＝与魔女结盟的异能破维魔。★ **全体都是「破维魔盟友」**——与对应魔女**可能有摩擦矛盾**，但**不存在完全敌对**。**不是「敵友两义」，也不是"先打后收服"**；且**并非人人一开始就有**（小说里狸眼当时「没有眷魔」）。
7. **关卡＝番街**：**零番街（下町）／壱番街（办公区）／弐番街（欢乐街）／参番街（农园地区）／肆番街（科学研究特区）** 为 **REGENERATE 官方页**定位；**伍番街（工业／工场地区・旧眼裏町）与陸番街（立入禁止区画）** 官方网页未给，**沿用 NARRATIVE（TRPG）CITYGUIDE** 并已标注出处（**不是本作自创**）。
   ★★ **番街的官方英文＝`Area 0`〜`Area 4`**（VIRTUAL REALITY 官方 EN 页，2026-10 采集）；官方中文**保留「○番街」不译**、只译地区性质。详见 [`research/official_srd_en_cn.md`](research/official_srd_en_cn.md)。
8. **每个番街背后有势力**：参番街＝**ヰ世界救済教団**（魔女崇拜教团，奉夜河世界为「**活神**」，【官方】）；弐番街＝**台風眼**（派流率领的不良少年团/黑帮，本作设定）；肆番街＝**復興課**。
9. **元进度＝復興率**（協奏中正典：打歌→提升復興率→解锁剧情）。玩家身份＝**観測者**（被召唤者）。
10. **名称纪律**：**角色 ≠ 声优**。游戏内一律显示角色名（森先化歩…），「花譜」等只出现在「声 — ○○」的 CAST 标注里。

## 5. 更新纪律

1. 新增/修正设定 → **同时**更新 `worldview.md` 或 `related-settings.md` 的**对应章节**、**§11 交叉核对**（若有矛盾）、以及本文档 §2 的「用了/没用」表。
2. **改了游戏内设定** → 同步 `DESIGN.md`（设计决策）与代码注释里的出处标注。
3. **采集到新证据** → 原样转录进 `docs/lore/research/`，再在详录里引用它，**不要**只把结论写进详录。
4. **拿不到出处就写「未找到」**，并列出试过的关键词；**永远不要编造**。
5. **新增/修订音乐发行**（新专辑、新单曲、新组合）→ 更新 `discography.md` 对应章节、**§1 计数**与 **§7.2 缺口**；平台补录的条目必须保留【平台】标记。
6. ★ **`discography.md` 只记录原创曲、合作曲及其衍生，不记录翻唱**（2026-10-22 定的长期规则，详见该文 §0.1b）。新增条目先判断是不是翻唱，**拿不准就问人类**，不要猜。
