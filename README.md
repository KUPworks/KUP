> 非官方同人致敬作品 —— 基于 KAMITSUBAKI STUDIO「神椿市」世界观的吸血鬼幸存者 like 游戏（v0.10.0-pool）。
> Inspired by 《神椿市建設中。》动画／《神椿市協奏中。》音游。与官方无任何关联。

## 运行方式

零依赖，无需构建：

- **直接双击打开 `index.html`** 即可游玩（WebAudio 需要一次点击激活，进入游戏点击「开始净化」即可）；
- 或启动本地静态服务器（推荐，后续版本带资源加载时必须）：

```powershell
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 玩法（5 分钟一局，局与局之间构成循环）

| 时间 | 事件 |
|---|---|
| 0:00 | 横幅「**『Q』発生**」（怪異事件；关卡＝番街，章节名取自动画各话副标题） |
| 0:00–1:30 | 基本型テセラクター涌来，发育、拾取「音片（フラグメント）」（经验） |
| 1:30 / 2:30 / 3:30 | **異能テセラクター（精英）** 出现，掉落回复 ♥ 与**記憶の卵**（20%） |
| 4:00 | **大テセラクター〈消音〉**（Boss）接近，释放音波环（陸番街提前至 3:30） |
| 5:00 | Boss 暴走（移速 ×1.8）——暴走后才击破 → **惨胜结局分歧** |

- **移动**：WASD / 方向键，或按住鼠标 / 触摸（魔女朝指针移动）；攻击全自动。
- **冲刺**：`Shift`（或点 HUD 的 `»`）——位移 + 0.4s 无敌帧，可躲开预警中的敌袭。
- **瞄准**：`V`（或点 HUD 瞄准按钮）——自动瞄准／鼠标瞄准／移动瞄准。
- **升级屏**：`1/2/3` 选择 · `R` 重掷 · `B` 切换封禁模式（再按数字键封禁该卡）。
- **浄化の歌**：`Space`（充能满 100）——清屏 + **清除全部敌方攻击**。
- **浄化の歌**（Space，动画第2話副标题 ★）：击破充能，满 100 释放清屏冲击环、冲散敌方音波环。
- **升级**：拾取音片升级，三选一（新武器 / 武器升级 / 被动强化 / 回复 / **觉醒**），按 `1/2/3` 快速选择。
  「系谱之心」升级时最大生命 +25% 并**回满**；「魔女的休息」回复 40%；回复音片 ♥ 回复 30%。
- **覚醒** ★（REGENERATE「魔女の娘へと覚醒する場面」）：初期武装满级后再次选中 → **觉醒演出**，武器化为乐曲名进化形态（如「わたしの声 -unison-」）。
- **記憶の卵** ★（动画第6話）：精英掉落 / 击破 Boss 必得 → 主菜单「记忆图鉴」解锁观测者的记忆片段，復興率 +1%。
- **出撃前配置**：番街（官方定位见下表）→ 角色（魔女之子／已招募的魔女候補）→ **皮肤**（特殊歌唱用形態／黑・白）→ **同伴**（需招募）＋同伴皮肤（**復興課 JK 制服・夏服／冬服**）。选择会记入当前槽位存档（并作为下次「再次净化」的默认配置）。
- **招募**：**通关参番街**→ 天祢亜留加入；**復興率 55%**→ 地邑阿栖加入；**通关肆番街**→ 同伴 彩季詩得加入。解锁后即可在选人界面选用／带出（结算页会提示新加入者；v0.6 起招募需在瓦利斯支付市民票）。
- **胜利**：击破 Boss（浄化完了）。**失败**：生命归零（信号消失，也计上观测数据）。
- **復興率循环** ★★（協奏中正典）：一局结束 → 復興率提升（首通 +12% / 重复 +2% / 败北 +1% / 每枚卵 +1%）→ 达阈值**解锁下一番街**（壱番街 8% → 弐番街 20% → … → 陸番街 70%）。
- `Esc` 暂停 · `M` 静音 · `Space` 浄化の歌 · HUD 右上角按钮同功能。
- **番街主题**：每区独立波次表与章节演出事件（壱番街「悪意」增援潮／弐番街「欲望」増殖／参番街「ファミリア」巨躯群／肆番街「現象」高速群／伍番街「ブラックアウト」视野遮蔽／陸番街「再生」终盘），以及独立地图主题（温室田垄／烟囱／锈迹骨架／残骸）、**各自的势力**（见下表）。

## 存档 / 观测记录（多槽位 · v0.7）

进度**不放在单个 localStorage 键里**，而是统一经由存储层 `js/store.js` 管理，主菜单「💾 存档 / 观测记录」进入槽位界面。

| 键 | 内容 | 是否按槽位 |
|---|---|---|
| `kup.settings` | 语言 / 音量 / BGM / SFX / 静音 | ❌ 全局共享（客户端偏好） |
| `kup.slots` | 槽位索引：`{ active, seq, list:[{id,name,createdAt,playedAt,playtime,runs,wins}] }` | — |
| `kup.save.<id>` | 该槽进度：復興率/市民票/通关次数/記憶の卵/招募/商店等级/上次皮肤同伴/最佳记录/上次出击配置/累计统计 | ✅ 每槽独立 |
| `kup.corrupt.<key>.<ts>` | 坏档隔离副本（只增不改，便于事后排查） | — |

- **槽位操作**：新建 / 改名（卡片内联输入）/ 复制 / 删除（二次确认，且始终保留至少一个）/ 选用切换。
- **导入导出**：导出为一段 base64 文本（同时尝试写入剪贴板）；导入**一律作为新槽位**加入，绝不覆盖现有档。导入会按 schema 版本迁移并做结构校验。
- **数据安全**：写入是**两阶段提交**（先写 `.tmp` 回读校验，再提交正式键并回读），配额爆/隐私模式不会破坏盘上旧值；解析失败的档会被隔离后重置，而不是静默从零开始把坏档刷掉。
- **不静默失败**：`localStorage` 不可用时退化为内存档并在界面提示「本次进度仅在内存中」；写入失败会在存档界面显示原因。
- **幂等结算**：每局有 `runId`，`META.addRunResult()` 对同一局只结算一次（不再依赖 UI 状态机防重复）。
- **多标签页**：监听 `storage` 事件，另一标签页写入时自动重载当前槽并提示，避免静默互相覆盖。
- **旧键升级**：`kup_meta` / `kup_best` / `kup_vol` / `kup_lang` 在启动时一次性升级进 s1 槽与全局设置，随后删除。

回归测试（无需浏览器）：`node tests/save.test.cjs`

## 升级池体验：分桶保底・重掷・封禁（v0.10）

原先三张卡从全部候选里纯随机抽（14 被动抢 5 槽），常出现「三张都不想要」。现在：

| 机制 | 说明 |
|---|---|
| **四桶保底** | 抽取顺序：①**覚醒卡优先**（满级初期武装）→ ②**武器／被动／道具各取 1**（凑齐「新武器·成长·应急」）→ ③余位从全部候选补足 → ④不足补 heal；最后**打乱位置**（不再「闭眼点第一格」） |
| **生存优先** | 血线 **<45%** 时，道具配额升为 **2 格且优先抽取**（自动瞄准类保底不变） |
| **重掷** | 每局 **3 次**（`R` 键或「⟳ 重掷」按钮）；只重掷**尚未选择**的三张；耗尽后按钮置灰 |
| **封禁** | 卡右上角 **`✕`**（或按 `B` 进入封禁模式后按 `1/2/3`）→ 该选项**本局不再出现**，该格**立即换成新候选**（其余两格保留）；`heal` 等无 id 卡不可封禁 |

> 触屏/鼠标玩家直接用卡片上的 `✕`；键盘玩家用 `B` 切换封禁模式（按钮发光、提示行切换），再按数字键封禁。

## 局内道具：护盾・MISS・回血（v0.9）

升级三选一里**直接可选**的四种「符」——与被动强化分开：**不占被动槽位（被动上限 5 种）、可重复选择**，
血线低于 45% 时它们出现的权重会提高。

| 道具 | 效果 |
|---|---|
| **防音の符** | 立即 **+60 护盾**（可暂时超过护盾上限） |
| **無傷の符** | **15 秒内 MISS（完全回避）率 +25%** |
| **治癒の符** | 立即回复 **45% 最大生命** |
| **余韵の符** | **20 秒内每秒回复 4 生命** |

**局外 vs 局内**：瓦利斯（市民票）提供**永久小幅**强化——`薬膳スープ`（每秒回血 +0.5/级）、
`常連の勘`（MISS 率 +3%/级）；局内道具则是**即时/限时**的应急手段，两者叠加。

配套被动（也在升级池里）：

| 被动 | 效果／级 | 上限 |
|---|---|---|
| **余韵之癒** | 每秒回复 **1.0 生命**（战斗中也生效） | 5 |
| **無傷の譜** | **MISS 成功时**回复最大生命 **1.5%** | 5 |

> MISS 为**全局**机制：任何敌对伤害（近身、音波环、光束、毒区、轰炸）都会先判定回避，
> 成功则显示 `MISS` 且**完全不掉血**（基础 7%/级 + 瓦利斯 + 道具，上限 85%）。

## 环绕音球（狸眼初始武器）：体积与转速可调（v0.9）

谷置狸眼的初期武装「暴食音球」原先只有固定半径与固定转速，导致 **冷却提升对它毫无意义**，
且**贴到玩家身上的敌人永远打不到**（旧判定是「球心附近的圆」，敌人一旦进入环内就再也碰不到）。

现在改成可调 + 扫掠判定：

| 可调项 | 由什么驱动 |
|---|---|
| 环绕半径 | **范围**（`areaMult`：電脳領域被动／皮肤／规则修正） |
| 音球体积（判定粗细） | 同上——球径 = `11 × (0.72 + 0.28 × 范围)` |
| 旋转速度 | **冷却**（基础 `spin` ÷ `cdMult`；冷却越短转速越快） |
| 判定形状 | **沿「玩家→音球」的扫掠臂**（点到线段距离）——贴脸敌人同样会被环噬 |

等级数据新增 `spin` 字段（升级时同步提升转速），觉醒形态「食虫植物 -devour-」为 8 球 / spin 4.2。
回归测试断言：半径随范围增大、转速随冷却提升、范围不影响转速（两轴独立）、40 秒内确实能击杀。

## 瞄准：自动／鼠标／移动（v0.9）

非自动瞄准类武器（追唱の矢 `follow`／音枪 `lance`）原先只朝**移动方向**发射，手感受限。现在统一三种模式：

| 模式 | 行为 |
|---|---|
| **自动瞄准（默认）** | 朝**最近的怪异**；900px 内无敌人则退回移动方向 |
| **鼠标瞄准** | 朝**指针位置**（触屏按住即指向该处），可自由预瞄 |
| **移动瞄准** | 旧行为（朝移动方向），供习惯者使用 |

- 切换：`V` 键，或点 HUD 的瞄准按钮（图标随模式变化：`◎` 自动／`✛` 鼠标／`➙` 移动）
- URL：`?aim=auto|mouse|move`
- 追踪音符／音波环／投掷类本来就是自动瞄准，不受影响

## 敌方攻击与"可躲避"设计（v0.8）

### 为什么单独做 `Danger` 实体

v0.7 之前 Boss 直接复用玩家武器类（`Ring`/`Beam`/`Zone`），带来三个问题；v0.8 全部改为**敌方专属** `KUP.Danger`：

| 旧问题 | 现在 |
|---|---|
| 〈観測〉光束会**误伤破维魔**（借用了玩家光束的判定/视觉） | `Danger` 只对玩家判定；破维魔在光束/毒区里**毫发无伤**（回归测试逐项验证） |
| 〈爆塵〉轰炸刷新在玩家脚下，难以躲避 | 落点为**距玩家 150–300px 的环状点**（绝不贴脸），信管 0.95–1.15s |
| 敌方特效与玩家武器视觉重合，辨识度低 | 敌方统一**高对比外观**：品红/橙 + 斜纹填充 + 虚线边缘 + 收缩倒计时环 + 「!」标记，画在敌人**之上** |

| `?tickets=300` | 调试：临时发放市民票（测试瓦利斯商店）（**仅内存，不落盘**） |
| `?w=toss,bomb,mine` | 调试：追加初始武器（验证新武器组；最多带 5 把） |
| `?slot=s2` | 切到指定槽位后再执行其余调试（把调试写在一份独立档上） |
| `?reset=1` | 重置**当前槽**进度：復興率／记忆图鉴／招募／市民票／商店强化（不再影响其它槽位） |
| `?wipe=1` | 删除**全部**槽位存档，只剩一个空槽（清档测试用，危险） |
| `?lang=ja` | 界面语言（zh/en/ja） |
| `?aim=auto\|mouse\|move` | 瞄准模式（默认 auto＝自动瞄准最近的怪异） |
| `?seed=` | **随机种子**：决定街区布景与整局随机流（同 seed + 同区 = 同一局，可复现）；URL 指定时锁定（不随机化） |
| `?area=` | **番街**：`area0`〜`area6`（零番街〜陸番街；UI 中由復興率解锁，URL 直开仅提示不阻止） |
| `?mod=` | **规则修正**（「不可解空間」接口）：当前仅 `none`；未知 id 会 `console.warn` 并回落 |
| `?form=` | **皮肤（形態）**：魔女之子 `ouranchou`(花魁鳥)/`himerenjaku`(姬連雀)；魔女候補 `kuro`(黑)/`shiro`(白)。与角色类型不匹配时回落通常形態 |
| `?companion=` | **同伴**：`ciel`（彩季詩得；未招募则本局单独出击） |
| `?cform=` | **同伴皮肤（JK 制服）**：`jk_summer`(夏服)/`jk_winter`(冬服) |

> 一局（run）由 `{ char, area, mod, seed, companion, form }` 六个字段完整描述——凑齐即可复现任意一局。
