## 一、运行方式（部署）

**零依赖、无构建。** 两种方式：

```powershell
# 方式 A：直接双击 index.html 即可游玩
#   （WebAudio 需要一次点击激活 —— 进游戏点「开始净化」即可）

# 方式 B：本地静态服务器（推荐）
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

- 部署到静态托管（GitHub Pages / 任意 web 服务器）：**把仓库根目录整个上传即可**，没有构建步骤、没有环境变量、没有后端。
- 唯一要求：**现代浏览器**（用到 Canvas 2D、WebAudio、`localStorage`、ES2018+）。
- 没有 `localStorage` 也能玩（会退化成内存档并在界面提示）。

## 二、怎么玩

一局 **5 分钟**，局与局之间构成元进度循环。

### 2.1 一局的时间轴

| 时间 | 事件 |
|---|---|
| 0:00 | 横幅「**『Q』発生**」（关卡＝番街，章节名取自动画各话副标题） |
| 0:00–1:30 | 基本型テセラクター涌来，发育、拾取「音片（フラグメント）」（经验） |
| 1:30 / 2:30 / 3:30 | **異能テセラクター（精英）** 出现，掉落回复 ♥ 与**記憶の卵**（20%） |
| 4:00 | **大テセラクター**（Boss）接近（陸番街提前至 3:30） |
| 5:00 | Boss 暴走（移速 ×1.8）—— **暴走后才击破 → 惨胜结局分歧** |

**胜利**：击破 Boss（画面显示「浄化完了」）。**失败**：生命归零。

### 2.2 操作

| 操作 | 按键 | 触屏/鼠标 |
|---|---|---|
| 移动 | `WASD` / 方向键 | 按住画面（魔女朝指针移动） |
| 冲刺（位移 + 0.4s 无敌帧） | `Shift` | HUD 的 `»` 按钮 |
| 浄化の歌（清屏 + 清除全部敌方攻击） | `Space`（充能满 100） | HUD 大招按钮 |
| 切换瞄准模式 | `V` | HUD 瞄准按钮（`◎` 自动／`✛` 鼠标／`➙` 移动） |
| 升级三选一 | `1` / `2` / `3` | 点卡片 |
| 重掷（3 次/局） | `R` | 「⟳ 重掷」按钮 |
| 封禁某张卡（本局不再出现） | `B` 进封禁模式后按 `1/2/3` | 卡片右上角 `✕` |
| 暂停 / 静音 | `Esc` / `M` | HUD 按钮 |

**攻击全自动** —— 你只需要走位。武器由「歌声」具象化，拾取音片升级。

### 2.3 成长

- **升级**：拾取音片累积经验 → 三选一（新武器 / 武器升级 / 被动强化 / 回复 / **觉醒**）。
  - 三张卡走**四桶保底**（觉醒优先 → 武器/被动/道具各一 → 补足 → heal 兜底），**位置随机**；
  - 血线 **<45%** 时道具占 2 格且优先；
  - 「系谱之心」升级时最大生命 +25% 并**回满**；「魔女的休息」回复 40%；回复音片 ♥ 回复 30%。
- **覚醒**：初期武装满级后再次选中 → **觉醒演出**，武器化为乐曲名进化形态（如「わたしの声 -unison-」）。
- **記憶の卵**：精英掉落 / Boss 必得 → 主菜单「记忆图鉴」解锁观测者的记忆片段，**復興率 +1%**。

### 2.4 局内道具（四种「符」，可重复选，不占被动槽）

| 道具 | 效果 |
|---|---|
| **防音の符** | 立即 **+60 护盾**（可暂时超过护盾上限） |
| **無傷の符** | **15 秒内 MISS（完全回避）率 +25%** |
| **治癒の符** | 立即回复 **45% 最大生命** |
| **余韵の符** | **20 秒内每秒回复 4 生命** |

> **MISS 是全局机制**：任何敌对伤害（近身、音波环、光束、毒区、轰炸）都会先判定回避，成功则显示 `MISS` 且**完全不掉血**（上限 85%）。

### 2.5 躲避敌方攻击

所有敌袭都有**预警期**，预警期间只示警、不结算伤害：

| Boss | 攻击 | 预警 |
|---|---|---|
| 〈消音〉 | 音波环 + 召唤 | 0.5s |
| 〈緘黙〉 | 冲锋 + 沿途滞留带 | 0.45s |
| 〈誘惑〉 | 三段音波环（错开成"缝隙"） | 0.42 / 0.72 / 1.02s |
| 〈枯死〉 | 毒区（周期伤害） | 0.9s |
| 〈観測〉 | 旋转光束扫射 | 0.3s |
| 〈爆塵〉 | 环状轰炸 + 视野遮蔽 | 0.95–1.15s |
| 〈再生〉 | 阶段1 音波环／阶段2 轰炸 + 精英 | 0.5s / 1.05s |

> 敌方攻击一律**高对比外观**（品红/橙 + 斜纹 + 虚线边缘 + 收缩倒计时环 + 「!」），画在敌人之上。
> 有未生效敌袭贴近时，HUD 显示「**⚠ 危険 —— 回避せよ**」并加强屏幕红晕。

## 七、存档与观测记录

主菜单「💾 存档 / 观测记录」→ 多槽位管理。

- **槽位**：新建 / 改名 / 复制 / 删除（二次确认，始终保留至少一个）/ 选用切换。
- **导入导出**：导出为一段 base64 文本（同时尝试写入剪贴板）；导入**一律作为新槽位**加入，**绝不覆盖现有档**。
- **安全设计**：写入是**两阶段提交**（先写 `.tmp` 回读校验，再提交并回读），配额爆/隐私模式**不会破坏盘上旧值**；解析失败的档会被**隔离**（`kup.corrupt.*`）而不是静默清零。
- **不静默失败**：`localStorage` 不可用时退化为内存档并提示「本次进度仅在内存中」；写入失败会在存档界面显示原因。
- **多标签页**：另一标签页写入时自动重载并提示，避免互相覆盖。
- **旧档升级**：`kup_meta` / `kup_best` / `kup_vol` / `kup_lang` 启动时一次性升级进 s1 槽与全局设置。

> 技术细节（键结构、schema、幂等结算）见 [DESIGN.md](DESIGN.md#存档层)。

## 八、调试与作弊参数（URL）

```
index.html?t=235&lv=12&god=1&char=kaf&skip=1&xp=10&mv=1&hurt=0.5&pick=heart&gem=heal&lang=ja&area=area5&seed=777
```

| 参数 | 作用 |
|---|---|
| `?t=` `?lv=` | 起始时间（秒）／初始等级 |
| `?god=1` | 无敌 |
| `?char=` | 直接选角色：魔女之子 `kaf`/`rim`/`harusaruhi`/`isekaijoucho`/`koko`；招募角色 `aru`/`asu`（未招募时仅提示） |
| `?skip=1` | 跳过菜单直接开局 |
| `?xp=` `?mv=1` `?hurt=0.5` | 立即获得经验（触发升级）／自动向上行走／初始损失 50% HP |
| `?pick=heart,heal,ward` | 强制指定升级三选一（被动／武器／道具 id 或 heal） |
| `?reroll=N` | 本局重掷次数（默认 3；`0` 验证耗尽置灰） |
| `?gem=heal` | 周期生成回复/经验音片 |
| `?ult=1` | 开局即充满浄化の歌 |
| `?w=toss,bomb,mine` | 追加初始武器（最多带 5 把） |
| `?recruit=1` `?tickets=300` | 临时解锁全部招募／临时发放市民票（**仅内存，不落盘**） |
| `?form=` | 皮肤：`ouranchou`/`himerenjaku`（魔女之子）；`kuro`/`shiro`（魔女候補） |
| `?companion=ciel` `?cform=` | 同伴／同伴皮肤（`jk_summer`/`jk_winter`） |
| `?lang=` `?aim=auto\|mouse\|move` | 界面语言／瞄准模式 |
| `?seed=` `?area=` `?mod=` | **随机种子**（同 seed + 同区 = 同一局，可复现）／番街 `area0`〜`area6`／规则修正（当前仅 `none`） |
| `?slot=s2` | 切到指定槽位后再执行其余调试 |
| `?reset=1` `?wipe=1` | 重置当前槽进度／删除**全部**槽位（危险） |

> 一局（run）由 `{ char, area, mod, seed, companion, form }` 六个字段完整描述 —— 凑齐即可复现任意一局。

| **画法 / 背景 / 特效** | `js/render.js` | ⚠️ **渲染路径禁止调用随机数**（否则同 seed 不可复现） |
