## 一、运行方式（部署）

**零依赖、无构建。** 两种方式：

```powershell
# 方式 A：直接双击 index.html 即可游玩
#   （WebAudio 需要一次点击激活 —— 进游戏点「开始净化」即可）

# 方式 B：本地静态服务器（推荐）
python -m http.server 8080
# 浏览器打开 http://localhost:8080
```

- 部署到静态托管（GitHub Pages / 任意 web 服务器）：**把仓库根目录整个上传即可**，没有构建步骤、没有环境变量、没有后端。
- 唯一要求：**现代浏览器**（用到 Canvas 2D、WebAudio、`localStorage`、ES2018+）。
- 没有 `localStorage` 也能玩（会退化成内存档并在界面提示）。

## 二、怎么玩

一局 **5 分钟**，局与局之间构成元进度循环。

### 2.1 一局的时间轴

| 时间 | 事件 |
|---|---|
| 0:00 | 横幅「**『Q』発生**」（关卡＝番街，章节名取自动画各话副标题；**治安战没有章节名**，不会出现「治安戦 · 治安戦」这类重复） |
| 0:00–1:30 | 基本型／鸟型／人形杂兵混编涌来，发育、拾取「片段（フラグメント）」（经验） |
| 1:30 / 2:30 / 3:30 | **破维魔（強化型）** 出现，掉落回复 ♥ |
| 4:00 | **大テセラクター**（Boss）接近（陸番街提前至 3:30） |
| 5:00 | Boss 暴走（移速 ×1.8，攻击更密）—— **暴走后击破同样是普通胜利**（v0.15.2 起不再区分「惨胜」） |

**胜利**：击破 Boss（画面显示「浄化完了」）。**失败**：生命归零。

#### 破维魔的「体型」（v0.20.2）

破维魔按**体型**分成八形。体型只决定**参数原型**（快／慢／硬／大／转向灵），**不是另一套画法**——
场上仍是同一套多边形故障体，靠颜色、边数、大小与速度区分（v0.20.1 的剪影绘制已按人类要求回退）。

| 体型 | 谁是这个体型 | 手感 |
|---|---|---|
| 球型 | 基本型、〈消音〉 | 基线，所有数值居中 |
| 鸟型 | 鸟型（新杂兵）、〈爆塵〉 | 快一点、脆一点 |
| 人形（杂兵） | 人形・杂兵（新杂兵）、〈弾片〉（治安战） | 慢一点、硬一点、更疼 |
| 鱼形 | 高速型、〈誘惑〉 | 最快、血最少、转向最灵 |
| 爬行类 | 巨躯型、〈再生〉 | 慢、硬、撞击疼 |
| 人形 | 強化型（精英）、〈緘黙〉 | 血厚、稳、压迫感强 |
| 虫型 | 〈観測〉 | 敏捷（目前只有 Boss） |
| 植物形 | 〈枯死〉 | 最慢、最大、靠散播占场 |

- 新增的**鸟型**与**人形・杂兵**只是把基本型的刷怪权重拆出来（70 : 15 : 15），**总刷怪率不变**，不会更难。
- **Boss 是"先选体型、再单独调参"**：体型给手感（鱼/虫/鸟更灵、植物/爬行更重），血量与伤害按关卡顺序单独写，
  不继承同体型杂兵的数值。
- 体型是**设计分类**，不是阵营：与魔女结盟的使魔（眷魔／ファミリア）是另一层，**不会作为敌人出现**。

#### 不可解空間（v0.18）

Boss 出现时，有 **35%** 概率进入一处「**不可解空間**」——空间会把这一场 Boss 战的规则临时改写（横幅 + **顶部常驻「空间名 + 规则原文」**；v0.20.5 起规则不再只靠横幅一闪而过）：

| 空間 | 规则变化 |
|---|---|
| 過密空間 | 刷怪更密、敌人更脆、掉落更多 |
| 深霧空間 | 视野被浓雾吞没；拾取与经验提高 |
| 硬直空間 | 玩家移速下降；冷却缩短、伤害提高 |
| 静音空間 | 伤害提高，但**浄化の歌被封印**（充能条置灰） |
| 豊穣空間 | 拾取与经验大增；敌人更快 |
| 高熱空間 | 双方伤害同时提高 |
| 錯乱空間 | 每 25 秒随机改写为另一条空间 |

- 空間持续到**这场 Boss 战结束**（场上所有 Boss 都被击破），随后规则回归（横幅提示）。
- **治安战多体 Boss 并存时不会叠加**：同一时间只允许一处空间；触发体先被击破、但另一体还在时，空间**不会提前退出**（规则要等整场 Boss 战结束才回退）。
- 治安战每体 Boss 出现时都会尝试掷骰；若当前已有空间（或正在延迟展开）则跳过——所以一处空间结束后，下一体 Boss 仍可能再触发。
- 効果不是只作用于新刷的怪：进入/退出时，场上活着的敌人会按比例同步速度/伤害/血量。

| 操作 | 按键 | 触屏/鼠标 |
|---|---|---|
| 移动 | `WASD` / 方向键 | 按住画面（魔女朝指针移动） |

| 切换瞄准模式 | `V` | HUD 瞄准按钮（`◎` 自动／`✛` 鼠标／`➙` 移动） |

**攻击全自动** —— 你只需要走位。武器由「歌声」具象化，拾取片段升级。

### 2.3 成长

- **升级**：拾取片段累积经验 → 四选一（新武器 / 武器升级 / 被动强化 / 回复 / **觉醒**）。
  - 四张卡走**四桶保底**（觉醒优先 → 武器/被动/道具各一 → 补足 → heal 兜底），**位置随机**；
  - 血线 **<45%** 时道具占 2 格且优先；
  - 「系谱之心」升级时最大生命 +25% 并**回满**；「魔女的休息」回复 40%；回复片段 ♥ 回复 30%。
- **覚醒**：初期武装满级后再次选中 → **觉醒演出**，武器化为乐曲名进化形态（如「私論理 -theory-」）。
- **武器（v0.20：21 把 / 15 种行为）**：**武器 id＝歌与武装（数据）**、**模组 id＝行为实现**、**模组族＝大模组**，三层互不重名（如武器 `note`＝私論理，behavior 是模组 `homing`，属于大模组 `projectile`）。可招募角色的专属武器需先招募才会入池（v0.11）；近战挥刀「**斩音太刀**」以**扇形角度**与**刀长**为参数，圆形波（テラ・ドロップ等）亦可配**角度**变成定向扇形冲击波——两者都在 `js/data/weapon.js` 的等级表里用 `arc`（度）／`len`（px）调节。弹道大模组 `projectile` 含 `homing`（追踪）、`sniper`（贯通）、`machinegun`（**弹夹 mag＋换弹 reload**）、`shotgun`（**总散布角 spread**）、`typhoon`（巨大重弹）；另外 `devour`（聚怪群伤）、`chain`（最近怪连锁）、`summon`（召唤幻影）各自成系。
- **「范围」对所有武器都有效**（v0.13.1）：角色／形态／被动「電脳領域」带来的范围加成，会**成比例放大每把武器的作用尺寸**——环绕音球的**球体体积**与环绕半径、太刀**刀长**、冲击环与冲击波的半径、光束长度、音符与音枪的**命中半径**、投掷距离与滞留区半径、空爆与地雷的作用半径。哪些参数放大、哪些刻意不变（如光束宽度、音符飞行距离）全部写在 `KUP.WEAPON_MODULES[*].area` 里。
- **环绕音球（暴食音球，v0.15.1）**：判定是**球体本身碰到敌人**（不是「玩家到球的那条线」），球体**贴着玩家转**（环绕半径 Lv1 46 → Lv5 54 → 覚醒 58）。转速按「**半圈律**」标定：普通破维魔走过球体直径的这段时间里，武器恰好转半圈，它会在接触窗口里吃到 2–3 次命中——所以**能被打死**（开局 10 血、4 分钟后 23 血都测得穿）。为了不吃亏，它的球体更大（11→19…24）、单发更痛（Lv5 17→22、覚醒 20→28），实测实战输出与上一版持平。
- **音之地雷（v0.15.1）**：地上只画**很小的一枚**（显示缩放 0.32，面积约 1/10）＋一圈淡虚线的**触发圈**；破维魔踏进触发圈（半径 ＝ 爆炸半径 ×0.6）才起爆，爆炸按更大的**击杀半径**结算——起爆瞬间会推出**向外扩散的圆**（先到触发半径、再到击杀半径），把真实范围一次性"摊"给你看。
- **記憶の卵（v0.17：局内「現象」卡）**：**极低概率**在升级四选一里出现，**和普通卡一样占一格、固定第 4 张**（番街一局最多出现一次；治安战在充能耗掉后可再次抽到）。选中＝用这次升级换 **1 次復活**：生命归零时自动回 **50% 生命**、释放**小范围冲击波**（伤害＋击退，半径 240）、并获得 **2.5 秒无敌帧**。**不产出任何局外进度**（旧版图鉴/復興率 +1% 已移除）；**胜利结算后不能再復活**。
- **角色大招（v0.14：每个角色都不同）**：击破充能满 100 → `Space` 释放 → 清零并进入**冷却**（各角色时长不同）。效果全部由 `js/data/char.js` 的 `KUP.ULTIMATES` 定义：

  | 角色 | 大招 | 效果 |
  |---|---|---|
  | 森先化歩 | **双极谐振** | 双重反相冲击环横扫全场（伤害 ×3.2 / ×2.4），冲散全部敌袭 |
  | 谷置狸眼 | **静止帧** | 全场怪异冻结 3.2s（Boss 减免）+ 回血 15% + 冲散敌袭 |
  | 朝主派流（春猿火） | **九龍噴火** | 朝瞄准方向喷 **160° 扇形烈焰**（×4.5，最高单发伤害），小火回血 |
  | 夜河世界 | **星海陷落** | 全场**减速至 35% 持续 10 秒** + 留下 4 处星屑滞留区（控场型） |
  | 輪廻此処 | **终结弹幕** | 向 **12 个方向**同时打出贯穿光束（各 ×1.6） |
  | 天祢亜留 | **救済の聖歌** | **回复 40% 最大生命 + 3 秒无敌**（支援型） |
  | 地邑阿栖 | **終楽章・箭雨** | **16 方向**放射贯穿箭雨（各 ×1.3） |

- **会心（暴击，v0.18.3／v0.18.4）**：所有玩家伤害都有机会「会心」，倍率与概率**按角色不同**，期望增伤都被压在 **1.08～1.10**（谁的数值都不白给），差别在「打得勤但单发小」还是「偶尔一发爆炸」：

  | 角色 | 会心率 | 会心倍率 | 期望增伤 |
  |---|---|---|---|
  | 森先化歩 | 12% | ×1.75 | +9% |
  | 谷置狸眼 | 18% | ×1.55 | +9.9% |
  | 朝主派流 | 8% | ×2.10 | +8.8% |
  | 夜河世界 | 15% | ×1.65 | +9.8% |
  | 輪廻此処 | 22% | ×1.45 | +9.9% |
  | 天祢亜留 | 10% | ×1.80 | +8% |
  | 地邑阿栖 | 14% | ×1.60 | +8.4% |

  - **会心率不常驻 HUD**：初始值写在**魔女介绍**里（出击界面选中角色后显示「初始会心 12% · 会心伤害 ×1.75」），局内想看完整状态请按 `Esc` 暂停（见下）。
  - **会心伤害**显示为金色「**会心 N**」；结算屏记「✦ 次数 · 最高单发」。
  - **Boss 的会心倍率 ×0.85**（Boss 血厚、一场打很久，避免"会心就是唯一解"）；会心率上限 60%、倍率上限 3.0。
  - **成长卡**：「**鋭音**」会心率 +4%／级、「**重音**」会心伤害 +0.20／级——两张都只加一项，期望分别约 +3%／级 与 +2.4%／级，**低于标准「力量 +12%」**；互相放大但同受上限约束。
  - **特殊触发（v0.18.4 起暂时注释）**：v0.18.3 的七种按角色会心特效已整体停用，代码保留在 `game.onCrit` 里备后续重做。
- **暂停界面（v0.18.4）**：`Esc` 暂停时显示本局**当前完整状态**——生命、护盾耐久/上限与当前减伤、回避率、会心率与会心伤害、等级、所持武器（含等级/覚醒）、是否持有記憶の卵。
- **瞄准规则（v0.14）**：投掷型（残留音块）会**分别投向最近的两个敌人**（每个音块各自追向自己那个目标）；激光双光束**分射最近的两个敌人**，只有一个敌人时**前后对穿**；射弹类（追唱之矢／音枪）的夹角**变小到约 5°**，能拿到不同目标时各打一个。
- **护盾（v0.20.3：耐久与保护效率分开，耐久 > 0 就一直减伤）**：护盾不吸收"血量"，而是按**受击类型给你减伤**——贴靠最高 95%、音波 85%、毒区 75%、轰炸 70%、光束 50%。
  - **耐久**：「防音护盾」每级 **+20 耐久**（20/40/60/80/100），挡下的伤害会**消耗耐久**；**只要耐久 > 0 就一直有减伤**，耐久打空才暂时失去减伤。
  - **保护效率**：1～4 级一律 **88**（贴靠 89%，相当于原来的第四级），**第 5 级才升到 100**（贴靠 95%）——等级先加"能扛多久"，满级再加"挡得多好"。
  - **恢复**：**脱战 3 秒**后，在 **1.5 秒**内自动回满（期间再受伤则重新计时）。HUD 显示 `盾 当前/上限 · 近身减伤 %`，残盾时整行变暗。
  - **防音の符**：+60 耐久、并额外 **+12 保护效率**（封顶 100；没有被动护盾时也能单独挡）。
  - **唯一规则：只要耐久 > 0，任何伤害类型都照常减伤**，耐久归零才失去（v0.20.3 起删除了"挡一次后失效""被光束/轰炸打穿后失灵"两个窗口）。

### 2.4 局内道具（七种「符」，可重复选，不占被动槽）

| 道具 | 效果 |
|---|---|
| **防音の符** | **30 秒内 +60 耐久、+12 保护效率**（不是回血；没有被动护盾时也能单独挡） |
| **無傷の符** | **15 秒内 MISS（完全回避）率 +25%** |
| **治癒の符** | 立即回复 **45% 最大生命** |
| **余韵の符** | **20 秒内每秒回复 4 生命** |
| **磁石の符**（v0.11） | **8 秒内全场片段被吸向魔女**（回复 ♥ 同样被吸引；可叠加续时） |
| **凍結の符**（v0.13） | 全场怪异 **2.6 秒僵直（冷冻）**：不动、不攻击、**无接触伤害**（Boss 减免 50%、精英 75%） |
| **鈍足の符**（v0.13） | 全场怪异 **8 秒减速至 50%**（与滞留音场减速叠加，取最强） |

> **状态异常机制（v0.13）**：敌人有**僵直（冷冻）**与**减速**两种状态——
> 冷冻＝完全停止（含 Boss 的行动计时器一起冻结），减速＝速度乘倍率（取最强来源、时间取最长）。
> 两个状态都会在敌人身上显示（冰晶覆盖／蓝色光环），施加入口为 `game.applyFreeze` / `game.applySlow`。

> **MISS 是全局机制**：任何敌对伤害（近身、音波环、光束、毒区、轰炸）都会先判定回避，成功则显示 `MISS` 且**完全不掉血**（上限 85%）。

> **片段的掉落配额与存活期（v0.18.1）**：击杀掉落按**空间格**配额——每 **240px 方格最多 160 个**，
> 同一格满了之后不再生成新片段，而是把经验**合并进该格已有的片段**（优先并进经验片段，
> 不会因为场上恰好有回复 ♥ 就吞掉经验）。片段 **5 分钟**内没被拾取会**直接消失**（不结算经验）。
> 全局另有 480 的兜底上限，防止长期不捡导致实体堆积。参数在 `js/config.js`：
> `GEM_CELL` / `GEM_CELL_CAP` / `GEM_LIFE` / `MAX_GEMS`。

| 〈消音〉 | 音波环 + 召唤 | 0.5s |
| 〈緘黙〉 | 冲锋 + 沿途滞留带 | 0.45s |

### 5.2 治安战（无尽关卡 · v0.13）

番街选择里的第 8 张卡（`∞ 治安战`，**恒可出击**、不占復興率解锁链）。

**「最佳成绩」只显示治安战**（v0.15.2）：主菜单的成绩行只保留治安战的最高记录；番街（主线）的战绩不再单独记录/显示——主线的进度看「復興率」与各番街的通关次数就够。

| 规则 | 说明 |
|---|---|
| **无尽** | 波次每 **30 秒**推进（横幅提示），刷怪率与怪种逐波升级；每 **45 秒**一体精英；Boss **首次 4 分钟**出现，之后**每 2 分钟**一体（7 体轮换，第 n 体血量 ×(1+n×0.35)） |
| **多体 Boss 并存** | 前一体还没打完又到点，就**同时存在多体**——各自独立行动、各自暴走；屏幕上方**每个 Boss 一行血条**依次排列（暴走的那条变橙色），击破其中一体只少一行、不会影响其余（旧版：只显示最新一体，且击破任一体血条整块消失） |
| **没有败北** | HP 归零只表示「**战斗结束**」——界面不写失败，也不写「信号消失」 |
| **击破 Boss ≠ 结束** | 击破 Boss 会清场并继续下一轮（不是通关） |
| **成绩独立** | 点数 ＝ `净化数×10 ＋ 存活秒数×2 ＋ 波次×100`，记入**治安战最高记录**（主菜单**唯一显示**的成绩、结算屏单独展示）；**不发復興率**；記憶の卵改为局内現象卡——充能耗掉后可再次抽到，因此**一场可復活多次**（概率依旧极低） |
| 收入 | 现金照常按净化数结算（市民票由现金兑换） |

> 相关按钮/文案：结算标题「战斗结束。」、按钮「再战一场 ▶」、HUD 常驻 `WAVE N`。

## 七、存档与观测记录

主菜单「💾 存档 / 观测记录」→ 多槽位管理。

- **槽位**：新建 / 改名 / 复制 / 删除（二次确认，始终保留至少一个）/ 选用切换。
- **导入导出**：导出为一段 base64 文本（同时尝试写入剪贴板）；导入**一律作为新槽位**加入，**绝不覆盖现有档**。
- **安全设计**：写入是**两阶段提交**（先写 `.tmp` 回读校验，再提交并回读），配额爆/隐私模式**不会破坏盘上旧值**；解析失败的档会被**隔离**（`kup.corrupt.*`）而不是静默清零。
- **不静默失败**：`localStorage` 不可用时退化为内存档并提示「本次进度仅在内存中」；写入失败会在存档界面显示原因。
- **多标签页**：另一标签页写入时自动重载并提示，避免互相覆盖。
- **旧档升级**：`kup_meta` / `kup_best` / `kup_vol` / `kup_lang` 启动时一次性升级进 s1 槽与全局设置。

> 技术细节（键结构、schema、幂等结算）见 [DESIGN.md](DESIGN.md) §6.0 的「存档层」与「结算幂等」两行。

|---|---|
| `?t=` `?lv=` | 起始时间（秒）／初始等级 |

| `?dmg=3` | 玩家伤害倍率（默认 1，仅调试用） |
| `?pick=heart,heal,ward` | 强制指定升级四选一（被动／武器／道具 id 或 heal） |
| `?egg=1` | v0.17：下一次升级**必出**「記憶の卵」現象卡（验证抽卡/復活；仍受"番街一局一次"限制） |
| `?revive=1` | v0.17：开局带 **1 次卵復活充能**（验证復活手感：回血/小 AOE/无敌帧） |
| `?auto=first\|last` | **自动采升级卡**（总选第 1／第 4 张；验证被动叠层、护盾 HUD、大招充能等需要频繁升级的效果） |
| `?reroll=N` | 本局重掷次数（默认 3；`0` 验证耗尽置灰） |
| `?solid=0` | 关闭建筑实体（楼体退回纯装饰，用于对比/回退；默认开启） |

| `?lang=` `?aim=auto\|mouse\|move` | 界面语言／瞄准模式 |
| `?seed=` `?area=` `?mod=` | **随机种子**（同 seed + 同区 = 同一局，可复现）／番街 `area0`〜`area6`／规则修正（当前仅 `none`） |
| `?space=off` / `?space=1` / `?space=<id>` | v0.18：Boss 战「不可解空間」——`off` 关闭、`1` 必进但随机、`<id>` 指定（`dense`／`fog`／`stiff`／`mute`／`bloom`／`heat`／`chaos`） |

| `?reset=1` `?wipe=1` | 重置当前槽进度／删除**全部**槽位（危险） |

## 九、想魔改？去动什么

零构建意味着**改完刷新即可生效**（浏览器缓存顽固时用 `Ctrl+F5`）。

> **数据层（v0.19 起）**：`js/data/` 一个玩法概念一个文件——
> `char`（角色/会心/大招）· `weapon`（模组＋武器）· `passive` · `item` · `enemy`（含 7 体 Boss）·
> `skin`（形態）· `support`（支援物品/同伴）· `shop`。**加载顺序的唯一真值是
> [`js/data/manifest.js`](js/data/manifest.js)**：加数据域＝建域文件＋在 manifest 加一条＋在
> `index.html` 补一行 `<script>`（`node tools/check-html.js` 会核对三者是否一致）。

> `node tools/inventory.js` 会打印模块清单与 audit 结果。域文件之间**不要互相引用**。

1. **不要在渲染/UI 路径里用随机数** —— 一律走模拟路径的随机流（`KUP.U.rng`），否则同 `seed` 复现不出来。

3. **不要引入 npm / 打包器 / 框架** —— 零依赖是项目核心约束。新增**运行时依赖**属于破坏性设计决定，必须先确认。
